# Hi, I'm Helin

### AI / Machine Learning Developer

I build **AI systems and developer-focused software**, with a strong interest in understanding and implementing the technologies behind modern intelligent applications.

My work is primarily centered around **Python and PyTorch**, with experience in **language models, neural networks, tokenization, attention mechanisms, Transformer architectures, training pipelines, optimization, and inference**. I also develop supporting software systems using **FastAPI, React, TypeScript, and C#**, working across backend, frontend, desktop applications, and deployment workflows.

Beyond model development, I’m interested in **code intelligence, static analysis, data-flow analysis, developer tooling, and AI-powered applications**. My goal is to grow as an **AI/ML Engineer capable of building complete systems end-to-end**, from model architecture and APIs to production-ready applications and deployment.

I’m especially interested in **LLMs, deep learning, RAG systems, AI tooling, developer tools, and research-driven engineering**.
